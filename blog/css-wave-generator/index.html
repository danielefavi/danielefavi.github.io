CSS wave generator

Set the parameters and regenerate the animated dot wave. The output is plain HTML and CSS you can copy into your own page.

Defaults: wave height 30px, dots number 10, dot delay 0.3sec, dot size 6px, cycle time 2.5sec, dot gap 6px, color #c0392b. Values follow the original V1 generator; dots are limited to 50 in this browser tool.

CSS Wave Generator

This is a CSS wave generator: just set the parameters below and get the CSS and HTML code! There is an explanation of the parameters at the bottom of the page.

Conversion note — interactive tool. The original page hosts an interactive generator: a live preview shows the animated wave of dots, and a form lets the visitor set the parameters — Wave Height (px) (default 30), Dots Number (default 10), Dot Delay (sec) (default 0.3), Dot Size (px) (default 6), Cycle Time (sec) (default 2.5), Dot gap (px) (default 6) and Color (default #c0392b) — then press the OK button to regenerate the preview together with the HTML and CSS code below (the Default button restores the default values). The interactive form cannot run in this Markdown copy; the code blocks below show the output generated with the default parameters. The working tool is available on the original page: CSS Wave Generator.

Parameters

  • Wave height: wave amplitude in pixel
  • Dot delay: time delay between two dots
  • Cycle time: time required for a dot to go up and down one time
  • Dots number: total number of the dots in the wave
  • Dot size: size of a dot in pixel
  • Dot gap: distance between two dots
